What you can make

Interactive Guilloché Pattern Generator

Build precise ornamental patterns, layered engraving studies and generative line art that can remain geometric or develop into dense woven fields.

How the process works

Rotating geometry and linked oscillators drive each drawn path. Frequency, phase, routing and pen settings turn the machine into a flexible geometric pattern generator.

Inputs and source material

Begin with a built-in machine configuration and shape it through oscillator, rotation, routing and drawing controls.

Save and export

Export raster PNG artwork, genuine vector SVG paths or a recording of the drawing in motion.

Getting started

How to use Guilloché

  1. 01Choose a starting machine configuration and adjust the oscillators and rotation.
  2. 02Draw passes, change the pen style and layer the resulting geometric paths.
  3. 03Set the canvas dimensions, export PNG or SVG, or record the drawing in motion.
