A machine by Travers MacMaster

Recursive Symbol Machine

Recursive Symbol Machine is a standalone GPU visual instrument that turns one symbol into nested, radial, spiral, branching, tunnel, orbit, grid or cascading compositions. Shape recursion, transforms, motion and color, then save a PNG or record the result.

Inside the instrument

What it does

  1. 01Load a symbol or use built-in shapes
  2. 02Nested, radial, spiral, branch, tunnel, orbit, grid and cascade structures
  3. 03Recursion depth, copies and scale falloff controls
  4. 04Direct position, scale, rotation and mirror controls
  5. 05Animation, modulation and color controls
  6. 06Save and load presets
  7. 07PNG export and canvas or window recording
