BASEMENT

1.0 / WINDOWS x64 / VST3

A MIDI-played bass synthesizer with four oscillator layers, filtering, drive and disperser processing.

Load BASEMENT as an instrument on a MIDI track. Play notes and balance the four oscillator layers.

Download BASEMENT 1.0 ↓SHA-256 checksum ↓ZIP / 3.9 MB

Installation

  1. Extract the ZIP.
  2. Close your music program, then copy the complete .vst3 folder to C:\Program Files\Common Files\VST3\.
  3. Reopen your music program and rescan plugins if needed.

Read the included README for each plugin’s first-use instructions. These packages require a Windows x64 VST3 host and contain no standalone applications.

Download-package version: 1.0. Embedded plugin build versions are listed in each README.
