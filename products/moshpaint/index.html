MoshPaintGlitch Art & Experimental Painting Tool

MoshPaint is a browser and Windows image and video painting tool with five live processing engines, shared color masks, Moirefield fills and linked Zoom Loop canvases. Create nested crops, edit each one in a full-canvas view, and keep the pixel changes aligned across the linked views.

What you can make

Glitch Art & Experimental Painting Tool

Make layered digital glitch art, still image treatments and animated video-painting performances using imported media as pigment.

How the process works

Paint imported media with image brushes or living video. Apply Temporal Sculptor, Frequency Weaver, Recursive Feedback, Chromatic Physics or Motion Ecology to each brush sample before it lands. Color Territories supplies shared color masks for routing video and supported engine effects through selected regions. Zoom Loop creates same-aspect canvases from clicked areas; each crop opens in a full-canvas view, and edits map to shared pixels across the linked views.

Inputs and source material

Import images or browser-compatible videos into source wells, capture a camera clip, or create gradient, noise and Moirefield pigment.

Save and export

Save editable projects and export PNG, JPG or WebP stills and WebM motion in the browser. Supported browsers preserve timed-export cadence. The Windows application also supports MP4 and GIF.

Getting started

How to use MoshPaint

  1. 01Open MoshPaint in the browser and add an image, video or camera clip to a source well.
  2. 02Choose a Live Brush Engine and mode to process image or video samples as you paint. Use Color Territories to select shared color masks, then route a supported effect through the selection.
  3. 03Choose Zoom Loop, click an area to create a linked same-aspect canvas, then select that canvas to edit it in full view. Your changes remain registered across the original and linked views.
  4. 04Save the editable project or export a still or WebM video. Match export FPS to the source; use Live Record for real-time canvas or form movement.
