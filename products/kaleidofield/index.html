What you can make

Video & Image Kaleidoscope Generator

Turn photographs, moving footage or generated light into still image-kaleidoscope compositions and animated kaleidoscope studies built from radial patterns.

How the process works

Adjustable mirror geometry reflects the source through repeating wedges. Source position, rotation and Auto Movement continually reshape the symmetry without altering the original media.

Inputs and source material

Import an image or video, or begin with KaleidoField’s generated light field.

Save and export

Save a PNG or record video. The Windows version also supports seamless output-loop encoding.

Getting started

How to use KaleidoField

  1. 01Import an image or video, or start with the generated light field.
  2. 02Adjust the mirror geometry and source position. Use Auto Movement to explore changing symmetry.
  3. 03Choose the output dimensions and save a PNG or record video. Seamless output-loop encoding is available in the Windows app.
