MoshPaintglitch painting software

MoshPaint is glitch painting software by Travers MacMaster, developed as MoshPaint 2 Alpha. Paint with image and video pigment, distort strokes and build artwork with living video regions.

Windows alpha preview; browser edition is not yet available.

Inside the instrument

How to use MoshPaint

  1. 01Open the Windows preview and import an image or video into a pigment well.
  2. 02Paint with image brushes, create living video regions and use mosh or damage tools to reshape the artwork.
  3. 03Save the project or export a still. Motion export uses FFmpeg installed on the computer. A browser edition is not yet available.
