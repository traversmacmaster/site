# VST downloads

The public page is `/downloads/`, linked from the shared Menu. STRETCH, TimeField and BASEMENT have 1.0 distribution ZIPs, each containing its full Windows x64 VST3 bundle, README and file checksums. ZIP checksums sit alongside the files.

The plugin binaries are unchanged. Embedded build versions remain STRETCH 0.3.0, TimeField 0.15.1 and BASEMENT 0.9.0, documented in the packaged README and releases.json. The distribution version is 1.0. No compilation or plugin validation is claimed by this packaging task.
